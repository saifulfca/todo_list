          💾 Save data to a file

          Not linked to a file

          Link a file on your PC and TaskNest will auto-save every change to it. Unlike normal browser storage, this file survives clearing your browsing data — your tasks stay safe on your disk. If you ever lose the app's memory, just Open that file to restore everything.

          Your browser can't save directly to files. Use Chrome or Edge on Windows for auto-save. Meanwhile, the ⬇ Backup / ⬆ Restore buttons let you save and reload a data file manually.
